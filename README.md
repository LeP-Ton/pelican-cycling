# 鹈鹕慢行社 · 海岸投喂记

一只鹈鹕、一辆自行车，和六只等着开饭的小鹈鹕。

用原生 HTML、SVG、CSS 和 JavaScript 绘制的海岸骑行小游戏。所有内容都在 `index.html` 内，无需安装依赖，也可以离线游玩。

[开始游戏](https://lep-ton.github.io/pelican-cycling/)

## 玩法

在日落前沿海骑行，把鲜鱼投进六个喂食台上的鱼筐，最后抵达灯塔。

| 操作 | 按键 |
| --- | --- |
| 踩踏加速 | 按住 D 或右方向键 |
| 刹车 | 按住 A 或左方向键 |
| 甩喙投鱼 | 空格 |
| 暂停或继续 | P 或 Esc |

手机可以使用画面下方的按钮，同时按住踩踏并点按投鱼。

- 松开踩踏会滑行并恢复体力。
- 落点圆环对准筐口变绿时，投送更容易命中；出手后的落点也会受到车速变化影响。
- 轻装速度更快，满载有更多鲜鱼；海堤奖励较高，林荫路线恢复体力更快。
- 半程可以获得鲜鱼和体力补给，最高分保存在当前浏览器。

## 本地运行

直接使用现代浏览器打开 `index.html` 即可。也可以在项目目录启动静态服务：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署

仓库使用 GitHub Actions 部署到 GitHub Pages。推送 `main` 分支上的 `index.html` 或 Pages 工作流变更时，会自动更新网站；也可以在 Actions 中手动触发。

工作流只打包游戏入口与 `.nojekyll` 文件，不需要构建工具。
